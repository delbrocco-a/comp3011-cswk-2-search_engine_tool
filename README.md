# COMP3011 Coursework 2: Search Engine Tool

A command-line search engine that crawls [quotes.toscrape.com](https://quotes.toscrape.com/), builds an inverted index with TF-IDF scoring, and supports interactive search queries.

## Project Overview

The tool implements three core search engine components:

| Component | File | Description |
|---|---|---|
| Crawler | `src/crawler.py` | BFS web crawler with 6-second politeness window |
| Indexer | `src/indexer.py` | Inverted index with per-document TF-IDF scoring |
| Search | `src/search.py` | Conjunctive AND retrieval ranked by TF-IDF |
| CLI | `src/main.py` | Interactive REPL shell |

### Architecture

```
User input
    |
    v
main.py (REPL shell)
    |
    +-- build --> WebCrawler --> Indexer --> data/index.json
    |
    +-- load  --> Indexer.load(data/index.json)
    |
    +-- print --> SearchEngine.print_word()
    |
    +-- find  --> SearchEngine.find() --> TF-IDF ranked results
```

### Inverted Index Design

The index maps each word to a dictionary of URLs, each with a `Posting` record:

```
{
  "word": {
    "https://example.com/page": {
      "frequency": 3,
      "positions": [5, 12, 47],
      "tf_idf": 0.034821
    }
  }
}
```

**TF-IDF formula:**
- TF  = `frequency / document_length`  (normalised term frequency)
- IDF = `log(total_docs / docs_containing_term)`  (inverse document frequency)
- TF-IDF = `TF × IDF`

**Multi-word find** uses conjunctive (AND) processing: only pages containing _all_ query terms are returned, ranked by summed TF-IDF.

## Usage

Run the interactive shell from the project root:

```bash
python src/main.py
```

### Commands

| Command | Description |
|---|---|
| `build` | Crawl the site, build the index, save to `data/index.json` |
| `load` | Load a previously built index from `data/index.json` |
| `print <word>` | Print the inverted index entry for a single word |
| `find <word...>` | Find pages containing all given words (TF-IDF ranked) |
| `help` | Show command list |
| `quit` | Exit |

## Testing

Run the full test suite with coverage from the project root:

```bash
pytest tests/ -v --cov=src --cov-report=term-missing
```

Run a specific test file:

```bash
pytest tests/test_crawler.py -v
pytest tests/test_indexer.py -v
pytest tests/test_search.py -v
```

The test suite covers:
- URL normalisation and domain scoping
- HTTP error handling (mocked network)
- Politeness window enforcement
- Inverted index construction and TF-IDF computation
- Save/load round-trip fidelity
- Conjunctive search and TF-IDF ranking
- Edge cases: empty queries, missing words, empty index
